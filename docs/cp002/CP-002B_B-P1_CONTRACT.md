## Wire shapes and indexes (defined before code)

`previewRiceSheetBP1(input: unknown): SheetPreview`, `previewRiceGroupBP1(input: unknown): GroupPreview` use bounded typed plain data, not raw JSON. Exact own enumerable data keys; no optional omissions. Null represents unknown tare/price/group membership. No `undefined`, coercion, accessor or extra field. Untrusted JSON duplicate keys/depth/envelope/proxies/large graphs require upstream validation (same boundary as A-P1). Arrays dense plain arrays of explicit records; sparse *positions*, not sparse JS arrays. IDs are opaque case-sensitive ASCII tokens `[A-Za-z0-9][A-Za-z0-9._:-]{0,127}` (candidate technical grammar, not DB UUID or business identity policy).

Sheet: `{ownerId,sheetId,revisionId,groupId:string|null,batches:[{ownerId,sheetId,batchId}],slots:[{position:string,bag:null|""|{ownerId,sheetId,batchId,bagId,mode,raw}}],tare:null|{method:"proportional",scope:"sheet",bagsPerKg:RationalWire},priceVndPerKg:string|null,saleScope:"whole-sheet"}`. Required keys exactly as shown. `revisionId` is an explicit required canonical bounded identity token (same grammar, length and error codes as sheetId). The caller supplies it; never generate, infer, default, normalize or substitute it. The stable `sheetId` is distinct from revision metadata. `groupId` null only for standalone sheets. Batch membership explicit and validated; no batch tare. Empty slot declared by null or empty string in `bag`; absent position is also empty. Empty slots have no bag ID, weight or mode; raw empty inside an occupied bag record is malformed. Occupied bag mode `three-digit` = exactly three ASCII digits, 000 rejected, leading zeros preserved in raw and normalized with A-P1 (015 => 1500 g); `gram` = positive canonical integer gram string, explicit exact fixture/import adapter, not UI/import implementation. No fractional gross, negative, malformed or hidden extra fields. `saleScope` required; partial/other modes rejected. One price string, no list of prices. Tare ratio is exact positive reduced rational bags/kg, not fixed at 10. Null tare is missing, not no-tare. Extra impurity/discount/alternate deductions rejected.

Positions are canonical positive decimal strings, **1-based** global within sheet. Column-first: for zero-based ordinal `k=position-1`, row=`k%5+1`, global column=`k/5+1`, board=`k/25+1`, page=`k/75+1` (integer quotient), column-in-board=`(k/5)%5+1`, board-in-page=`(k/25)%3+1`. Index calculations are bounded structural metadata, not quantities. All output indices are strings. Explicit empty slot positions retained (empty string canonicalizes to null). Duplicate declared positions (including empty) rejected to avoid ambiguity; no compaction, no renumbering; missing positions do not count. `slotSpan` is maximum declared position, 0 if none. Output occupied column/board/page buckets only, sorted by numeric global index; absent bucket has count/gross 0 by definition, no dense expansion. Each bucket returns global index, count canonical integer string, grossGram rational wire. Sheet and group also return count/gross. Stable bag IDs and batch IDs unique within owner/group (stronger duplicate guard), sheet IDs unique within group, regardless of revisionId (two revisions of one stable sheet cannot coexist in a group). Different sheets may carry the same revision token; it is not a new global identity claim. No inference of identity from raw weight. Group input exactly `{ownerId,groupId,sheets:[SheetInput]}`; explicit same owner and group for all sheets. Sorted by ASCII sheetId; slots sorted by numeric position. Stable deterministic result independent of ordering valid slot/sheet arrays. No input mutation or external side effects.

## Exact result and missing data

Every weight/money/ratio is a canonical A-P1 RationalWire `{numerator,denominator}`; counts/indices and price are canonical integer strings. Use A-P1 parse, normalize-via-explicit adapter, add/multiply/divide/subtract/compare/round/convertMass for authoritative quantities; no Number coercion of quantities. `status:"PREVIEW"`, `profile:"B-P1 v1.0"` always. Sheet output: identities (ownerId, sheetId, revisionId unchanged, groupId), saleScope, slotSpan, slots (position, layout row/column/board/page, bag null or identity/raw/mode/grossGram), column/board/page buckets, count/grossGram, `tareRatio`, `tareGram`, `physicalNetGram`, `commercialNetGram`, `settlementGram`, `residualGram`, `priceVndPerKg`, `amountVnd`, `completeness`. Calculation: N=count, G=gross; T=1000*N/R; P=G-T; C=P; S=A-P1 nearest quantum 1000 g tie positive; residual=S-P; A=convertMass(S,g,kg)*price. One whole-sheet rounding, no money rounding, no persistence cast. T>G => EXCESS_TARE. Empty sheet count/gross 0, downstream null, completeness EMPTY; missing tare with bags => MISSING_TARE, downstream null; price missing with known tare => MISSING_PRICE, amount null; known zero net => COMPLETE when price known, amount 0/1, never finalized. All inputs validated even when downstream unavailable. Positive price required if supplied.

Group returns owner/group, ordered sheet previews, count/grossGram, `coverage` for each of tareGram, physicalNetGram, commercialNetGram, settlementGram, residualGram, amountVnd: `{knownSubtotal,completeValue,knownSheetCount,missingSheetCount,completeness}`. Sum only known canonical values (including zero); completeValue null unless at least one sheet and all known; knownSubtotal zero if none. Completeness EMPTY (no sheets), UNKNOWN (none known), PARTIAL (some known), COMPLETE (all known). Group amount missing count/status explicitly available under coverage.amountVnd. Group never rounds again. No interpretation as confirmed revenue, receipt, receivable or actual cash. All outputs preview only.

## Bounded profile and validation/error precedence

Candidate limits: at most 100000 submitted slot records (occupied plus explicit empty) per sheet and across a group, max slot position 1000000 per sheet, max 100000 batch records per sheet and across group, max 1000 sheets per group, max 128 ID characters. A-P1 256-token/reduced and 1024 temporary digits retained. No storage or annual cap; no dense arrays by span. Group checks cumulative slot/batch limits before any sheet calculation. Sorting O(n log n), sparse bucket storage O(n), bounded typed records; no promise of adversarial proxy/raw JSON resource safety. Metadata index/count bookkeeping is bounded; quantity accumulation is A-P1. Resource errors on any arithmetic intermediate or reduced result (including group sums) abort whole preview, not partial success. No signed64/numeric78 persistence constraint imposed on previews.

Stable RiceError.code union = A-P1 error codes plus DUPLICATE_ID, DUPLICATE_POSITION, PARENT_MISMATCH, UNSUPPORTED_PROFILE, EXCESS_TARE. A-P1 ArithmeticError.code translated unchanged; diagnostics not stable API. Precedence is deterministic, not global all-record A-P1 phases: (1) outer exact record keys / types, array length/resource before array member traversal; sheet/group identity grammar (sheet ownerId, sheetId, revisionId, groupId in that order) and root saleScope, (2) group member envelope/owner/group/unique sheet and cumulative resource checks in submitted order, (3) per sheet (sorted sheetId in group) tare shape/method/scope/ratio then price (A-P1 internal precedence), (4) batch shape/identity/parent/duplicate in submitted order, (5) slot shape/position positive/span/duplicate declared slot then bag shape/identity/parent/duplicate, mode/raw grammar/positivity in submitted order, (6) sorted layout sums and exact calculations, excessive tare before rounding; (7) sorted group coverage aggregation. Record/array descriptor validation occurs at its phase. Unsupported string method/scope/mode/saleScope => UNSUPPORTED_PROFILE; unknown fields => INVALID_SHAPE; non-string price (including multiple-price array) => INVALID_TYPE; invalid lexical input => NONCANONICAL; nonpositive quantity/position/price/ratio => DOMAIN; bounds => RESOURCE_LIMIT. Duplicate bag/batch/sheet IDs => DUPLICATE_ID; mismatched parents => PARENT_MISMATCH. Errors throw, never return partial result. No stateful operations, I/O, receipt or finalization.
